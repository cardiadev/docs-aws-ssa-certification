Bienvenido al módulo de **Services — Networking**. Esta sección cubre todos los servicios de red de AWS relevantes para el examen **SAA-C03**, desde la base de las Virtual Private Clouds hasta la distribución global de contenido.

## Temas

- **Amazon VPC** — redes virtuales aisladas dentro de AWS
- **Subnets** — segmentación de tu VPC en subredes públicas y privadas
- **Routing** — tablas de rutas y cómo fluye el tráfico dentro de una VPC
- **Internet Gateways** — conecta tu VPC a internet
- **NAT Gateways** — acceso a internet para subredes privadas
- **DNS (VPC)** — resolución de nombres dentro de tu VPC
- **Elastic IP** — direcciones IP públicas estáticas
- **Security Groups y NACLs** — firewalls stateful y stateless
- **Load Balancers** — distribución de tráfico con ALB, NLB y más
- **VPN** — conexión segura entre tu datacenter y AWS
- **Direct Connect** — conexión dedicada de baja latencia
- **VPC Peering** — comunicación directa entre VPCs
- **Transit Gateway** — hub centralizado para conectar múltiples VPCs
- **PrivateLink** — acceso privado a servicios sin pasar por internet
- **CloudFront** — CDN global para distribución de contenido
- **Lambda@Edge** — procesamiento en el borde con funciones Lambda
- **Global Accelerator** — mejora el rendimiento global con IPs Anycast
- **Route 53** — servicio DNS administrado y enrutamiento de tráfico
