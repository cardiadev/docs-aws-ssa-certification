Welcome to the **Services — Networking** module. This section covers every AWS networking service relevant to the **SAA-C03** exam, from the foundations of Virtual Private Clouds to global content delivery.

## Topics

- **Amazon VPC** — isolated virtual networks within AWS
- **Subnets** — segmenting your VPC into public and private subnets
- **Routing** — route tables and how traffic flows inside a VPC
- **Internet Gateways** — connecting your VPC to the internet
- **NAT Gateways** — internet access for private subnets
- **DNS (VPC)** — name resolution inside your VPC
- **Elastic IP** — static public IP addresses
- **Security Groups & NACLs** — stateful and stateless firewalls
- **Load Balancers** — traffic distribution with ALB, NLB and more
- **VPN** — secure connection between your data center and AWS
- **Direct Connect** — dedicated low-latency connection
- **VPC Peering** — direct communication between VPCs
- **Transit Gateway** — centralized hub for connecting multiple VPCs
- **PrivateLink** — private access to services without traversing the internet
- **CloudFront** — global CDN for content delivery
- **Lambda@Edge** — edge processing with Lambda functions
- **Global Accelerator** — improve global performance with Anycast IPs
- **Route 53** — managed DNS service and traffic routing
